الهاشم لخدمات رجال الأعمال - موقع ثابت مجاني
الملفات:
- index.html : الموقع الكامل المتجاوب مع العربية والإنجليزية
- logo.jpg : شعار المكتب

للنشر المجاني عبر GitHub Pages:
1) أنشئي مستودعًا عامًا جديدًا في GitHub.
2) ارفعي index.html و logo.jpg إلى جذر المستودع.
3) Settings > Pages.
4) اختاري Deploy from a branch ثم main و /(root) ثم Save.
5) انتظري حتى يظهر رابط الموقع في صفحة Pages.

الموقع لا يحتاج قاعدة بيانات أو اشتراك مدفوع لعرض المحتوى الثابت.
